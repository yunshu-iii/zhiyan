# zhiyan

zhiyan 是一个支持本地运行的多 Agent 研究与知识问答工作台，提供从问题拆解、信息检索到研究报告生成的完整流程。

## 主要功能

- **智能问答与意图分流**：根据问题类型选择直接回答或深度研究流程。
- **多 Agent 协作研究**：通过规划、检索、证据整理、分析、反思与写作等环节协同完成研究任务。
- **联网搜索与本地知识库**：结合网络信息和本地文档检索，支持文本与 Markdown 文档分块、向量化及语义查询。
- **迭代补充检索**：针对研究中的信息缺口生成补充查询，在设定的迭代次数内继续收集和分析证据。
- **报告引用与来源查看**：生成带来源标记的 Markdown 报告，展示网络链接与本地文档来源。
- **会话历史与上下文记忆**：保存完整对话，支持新建、切换、刷新恢复和分页查看历史会话，并提供会话记忆与语义记忆。
- **研究进度展示**：通过事件流展示研究阶段、执行状态和最终结果。

## 功能流程

提出问题 → 意图判断 → 任务规划 → 网络与本地检索 → 证据整理 → 分析与补搜 → 生成报告
